Responsibility

Owns
Persistent descriptions and frame-owned transient descriptions.
Identifies
Persistent instances with generation-checked RenderInstanceHandle values.
Produces
Filtered and stably sorted RenderItem values for the renderer.

Clear persistent and transient data.

Submission lifetimes

Persistent
Create once, update when source data changes, and destroy with its owner.
One frame
Submit a complete description each frame. Do not keep a handle.

Usage rules

  • Use persistent instances for scene objects and components.
  • Use one-frame draws for debug geometry, tools, and transient effects.
  • Call EndFrame after frame execution.
  • Do not store native graphics objects in render descriptions.

Related types

RenderInstanceHandle, MeshInstanceDesc, SpriteInstanceDesc, RenderItem, and Renderer.

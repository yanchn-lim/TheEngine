Frame sequence

  1. Begin the graphics frame.
  2. Collect visible render items.
  3. Resolve asset handles into GPU handles.
  4. Record the scene render pass.
  5. Leave the command list available for UI recording.
  6. End and submit the frame.
  7. Present the swapchain image.

Usage rules

  • Call EndFrame only after all command recording is complete.
  • Call Present only after successful submission.
  • Invalidate resources outside an active frame.
  • Call Shutdown before the device shuts down.

Related types

RenderWorld, RenderResourceManager, IGraphicsDevice, and IGraphicsCommandList.

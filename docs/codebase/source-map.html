TheEngine / source map

Source map

Use this page to locate subsystem entry points. Paths are relative to the repository root.

Source directories

  • GameEngine/src/coreWindow, engine lifecycle, time, file access, and common utilities.
  • GameEngine/src/renderingRender submission, render execution, and asset-to-GPU resource caching.
  • GameEngine/src/graphicsBackend-neutral graphics contracts, descriptions, handles, and factories.
  • GameEngine/src/graphics/openglOpenGL graphics device and OpenGL ImGui backend.
  • GameEngine/src/graphics/vulkanVulkan context, device, swapchain, frame resources, graphics device, and ImGui backend.
  • GameEngine/src/assetsAsset manager, registries, records, importers, and primitive mesh data.
  • GameEngine/src/ecsEntity handles, world ownership, sparse-set component pools, views, and typed queries.
  • GameEngine/src/platformGLFW window ownership, events, and resize state.
  • GameEngine/src/debugProfiler, memory tracker, profiler UI, log, and debug console.
  • GameEngine/src/testsGraphics tests and the current sandbox application.

Engine entry points

  • GameEngine/src/main.cppCreates the engine configuration, engine, and sandbox application.
  • GameEngine/src/core/application.hppDefines the callbacks that connect an application to the engine loop.
  • GameEngine/src/core/engine_config.hppDefines window and graphics startup configuration.
  • GameEngine/src/core/engine.hppDefines runtime service ownership and the application-facing engine API.
  • GameEngine/src/core/engine.cppCoordinates initialization, application callbacks, rendering, presentation, and shutdown.
  • GameEngine/src/platform/window.*Owns GLFW setup, events, resize state, and the native window.
  • GameEngine/src/tests/sandbox_application.*Owns the manual render test and debug overlay used by the executable.
  • GameEngine/Ludus.vcxprojDefines the compiler version, C++ language version, includes, libraries, and source files.

Rendering entry points

  • GameEngine/src/rendering/render_world.hppDefines the public persistent and one-frame render submission API.
  • GameEngine/src/rendering/render_world.cppImplements generation slots, updates, filtering, sorting, and frame cleanup.
  • GameEngine/src/rendering/render_item.hppDefines mesh and sprite descriptions and the RenderItem variant.
  • GameEngine/src/rendering/renderer.hppDefines frame execution, presentation, resize, and invalidation entry points.
  • GameEngine/src/rendering/renderer.cppCollects render items and records graphics commands.
  • GameEngine/src/rendering/render_resource_manager.*Creates, caches, invalidates, and destroys GPU resources for assets.

Graphics API entry points

  • GameEngine/src/graphics/graphics_device.hppDefines IGraphicsDevice, FrameContext, and FrameStatus.
  • GameEngine/src/graphics/graphics_command_list.hppDefines the backend-neutral graphics command order.
  • GameEngine/src/graphics/graphics_descriptions.hppDefines resource, pipeline, render-pass, and dynamic-state descriptions.
  • GameEngine/src/graphics/graphics_handles.hppDefines typed GPU handles.
  • GameEngine/src/graphics/resource_table.hppProvides generation-checked native resource storage.
  • GameEngine/src/graphics/graphics_device_factory.*Creates the selected graphics device.
  • GameEngine/src/graphics/imgui_backend.*Defines and creates the selected ImGui backend.

Backend entry points

  • GameEngine/src/graphics/opengl/opengl_graphics_device.*Implements the complete graphics contract with OpenGL.
  • GameEngine/src/graphics/opengl/opengl_imgui_backend.*Implements ImGui for OpenGL.
  • GameEngine/src/graphics/vulkan/vulkan_graphics_device.*Implements resources, commands, frames, and presentation with Vulkan.
  • GameEngine/src/graphics/vulkan/vulkan_context.*Owns the Vulkan instance, validation, and surface context.
  • GameEngine/src/graphics/vulkan/vulkan_device.*Selects and owns the Vulkan physical and logical device.
  • GameEngine/src/graphics/vulkan/vulkan_swapchain.*Creates swapchain images, views, format, extent, and presentation mode.
  • GameEngine/src/graphics/vulkan/vulkan_frameresources.hppDefines per-frame Vulkan command and synchronization resources.
  • GameEngine/src/graphics/vulkan/vulkan_imgui_backend.*Implements ImGui for Vulkan.

Assets and ECS entry points

  • GameEngine/src/assets/asset_manager.*Provides central access to asset registries.
  • GameEngine/src/assets/asset_handle.hppDefines typed CPU asset handles.
  • GameEngine/src/assets/asset_records.hppDefines the stored texture, shader, mesh, and material records.
  • GameEngine/src/assets/obj_importer.*Imports OBJ model data.
  • GameEngine/src/ecs/ecs_world.*Defines entity lifecycle, public component access, views, and ForEach queries.
  • GameEngine/src/ecs/ecs_entity.hppDefines the generation-checked entity handle.
  • GameEngine/src/ecs/ecs_component_view.hppDefines aligned non-owning entity and component spans.
  • GameEngine/src/ecs/ecs_component_pool*.hppImplements internal sparse-set storage and type-erased iteration support.

Diagnostic entry points

  • GameEngine/src/debug/profiler.*Records frame and scoped timing data.
  • GameEngine/src/debug/profiler_ui.*Displays timing and memory data in ImGui.
  • GameEngine/src/debug/memory_tracker.*Records allocation and per-frame memory data.
  • GameEngine/src/debug/debug.*Provides logging and the debug console.
  • GameEngine/src/tests/graphics_api_tests.*Tests handles, render submission, frame results, and invalidation.

Glossary

asset handle
Identifies CPU-owned engine content.
GPU handle
Identifies a resource owned by one graphics device.
render instance
Persistent render data stored in RenderWorld.
render item
One mesh or sprite description collected for execution.
graphics device
Owns GPU resources, frame submission, and presentation.
command list
Defines the ordered state and draw operations for one frame.
backend
Implements the graphics contract with OpenGL or Vulkan.
invalidation
Removes a cached GPU resource after its source asset changes.

TheEngine / Rendering

Rendering system

Rendering::RenderWorld is the public render submission point. Use the same API for components and direct code.

Choose a lifetime

Persistent instance

Create the instance once. Update it when source data changes. Destroy it when its owner is removed.

One-frame draw

Submit the complete description each frame. RenderWorld discards it after execution.

Use a persistent instance for a scene object or component. Use a one-frame draw for debug geometry, tools, effects, and code that does not own an entity.

Classes

RenderWorld
Owns persistent and one-frame render descriptions.
Renderer
Collects render items and executes one scene frame.
RenderResourceManager
Resolves asset handles into cached GPU resources.

Persistent submission guide

For the complete contract, read the RenderWorld reference.

A create operation returns RenderInstanceHandle. The handle contains an index and a generation. The generation rejects access through an old handle after slot reuse.

Rendering::MeshInstanceDesc desc{};
desc.mesh = meshHandle;
desc.material = materialHandle;
desc.transform = worldTransform;

Rendering::RenderInstanceHandle instance =
    renderWorld.CreateMeshInstance(desc);

renderWorld.SetTransform(instance, nextTransform);
renderWorld.SetVisible(instance, true);

renderWorld.Destroy(instance);
CreateMeshInstance(desc)
Creates persistent mesh data.
CreateSpriteInstance(desc)
Creates persistent sprite data.
UpdateMeshInstance(handle, desc)
Replaces the complete mesh description.
UpdateSpriteInstance(handle, desc)
Replaces the complete sprite description.
SetTransform / SetVisible / SetMesh / SetMaterial / SetLayers
Changes one field in an existing instance.
Destroy(handle)
Removes the instance and invalidates the old handle generation.

One-frame submission guide

For the complete contract, read the RenderWorld reference.

The draw operation copies the description into frame-owned storage. Do not keep a handle. Submit the item again if it must appear in the next frame.

Rendering::SpriteInstanceDesc desc{};
desc.texture = textureHandle;
desc.material = materialHandle;
desc.transform = worldTransform;
desc.tint = { 1.0f, 1.0f, 1.0f, 1.0f };

renderWorld.DrawSpriteOnce(desc);
DrawMeshOnce(desc)
Submits one mesh for the current frame.
DrawSpriteOnce(desc)
Submits one sprite for the current frame.
EndFrame()
Clears all one-frame submissions after frame execution.

Render descriptions

MeshInstanceDesc

The description contains a mesh, material, transform, layer mask, sorting order, optional entity ID, and visibility state.

SpriteInstanceDesc

The description contains a texture, material, transform, tint, UV rectangle, layer mask, sorting order, optional entity ID, and visibility state.

RenderItem is a variant of these two descriptions. This variant keeps both submission lifetimes on one renderer path.

Collection behavior

RenderWorld::Collect creates the list for one view. It rejects an invisible item. It also rejects an item when its layer mask does not intersect the view layer mask.

The collection uses a stable sort with sortingOrder. Items with equal sort values keep their collection order.

Frame execution

For the complete contract, read the Renderer reference.

  1. The renderer starts a device frame.
  2. It gets the active graphics command list.
  3. It starts one render pass for the swapchain color target.
  4. It collects visible render items.
  5. It resolves asset handles through RenderResourceManager.
  6. It binds the pipeline, buffers, constants, texture, and sampler.
  7. It records an indexed or non-indexed draw.
  8. It ends the render pass and clears one-frame render data.

Renderer::EndFrame submits graphics work. Renderer::Present presents the result. These operations remain separate so ImGui can record after scene rendering and before frame submission.

Ownership rules

  • RenderWorld owns render descriptions.
  • A component owns only its source fields and runtime render handle.
  • Renderer owns frame execution state.
  • RenderResourceManager owns cached GPU handles.
  • IGraphicsDevice owns native GPU objects.

Do not store a native OpenGL or Vulkan object in a render description. Use an asset handle or a backend-neutral GPU handle.

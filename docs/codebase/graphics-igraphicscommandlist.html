IGraphicsCommandList

namespace Graphics {
class IGraphicsCommandList {
public:
    virtual void BeginRenderPass(const RenderPassDesc& desc) = 0;
    virtual void SetPipeline(GpuPipelineHandle pipeline) = 0;
    virtual void Draw(uint32_t vertexCount) = 0;
    virtual void DrawIndexed(uint32_t indexCount) = 0;
    virtual void EndRenderPass() = 0;
};
}

Required order

  1. Begin the render pass.
  2. Set viewport and scissor.
  3. Set the pipeline.
  4. Bind vertex and optional index buffers.
  5. Set frame, material, and draw data.
  6. Record draws.
  7. End the render pass.

Usage rules

  • Use the command list only during its active frame.
  • Set all required state before a draw.
  • Keep bound resources valid until submitted work finishes.
  • Do not pass native backend objects.

AssetManager

Owns CPU asset registries and exposes one typed-handle entry point.

Owns

Returns
Typed CPU asset handles.

Usage rules

  • Keep asset handles separate from GPU handles.
  • Treat returned asset pointers as registry-owned data.
  • Invalidate cached GPU resources when source assets change.
  • Clear assets only after users stop accessing their records.

Related types

Typed asset handles, asset records, registry classes, and RenderResourceManager.

TheEngine / Graphics / IGraphicsDevice

IGraphicsDevice

Owns GPU resources, frame submission, and presentation for one graphics backend.

Graphicsclassgraphics_device.hpp

Declaration

namespace Graphics {
class IGraphicsDevice {
public:
    virtual bool Initialize(const GraphicsDeviceDesc& desc) = 0;
    virtual FrameStatus BeginFrame(FrameContext& context) = 0;
    virtual IGraphicsCommandList& GetCommandList(FrameContext& context) = 0;
    virtual FrameStatus EndFrame(FrameContext& context) = 0;
    virtual FrameStatus Present(FrameContext& context) = 0;
};
}

Responsibility

Owns
Native buffers, textures, samplers, shaders, pipelines, frame state, and presentation state.
Returns
Typed GPU handles and FrameStatus values.
Does not expose
Native OpenGL or Vulkan objects through public graphics headers.

Member functions

Device lifecycle

Initialize(desc)
Initializes the backend for the native window.
GetCapabilities()
Returns limits and supported backend features.
OnResize(width, height)
Updates or marks size-dependent resources.
WaitIdle()
Waits until submitted graphics work finishes.
Shutdown()
Releases device-owned state.

Resources

CreateBuffer / DestroyBuffer
Manage buffer data.

Manage sampled image data.

Manage texture sampling state.
CreateShader / DestroyShader
Manage backend shader programs.
CreateGraphicsPipeline / DestroyPipeline
Manage graphics pipeline state.

Frames

BeginFrame(context)
Acquires and prepares one frame.
GetCommandList(context)
Returns the command list for the active frame.
EndFrame(context)
Finishes recording and submits graphics work.
Present(context)
Presents the completed swapchain image.

Frame status

Success
Continue the current frame.
Skip
Do not record or present this frame.
ResizeRequired
Rebuild size-dependent state before a later frame.
DeviceLost
Stop rendering because the device is unusable.
Fatal
Stop the engine loop.

Usage rules

  • Check each FrameStatus before the next frame operation.
  • Destroy resources before device shutdown.
  • Call WaitIdle before shared device state is destroyed.
  • Do not use a handle with a different device.

Related types

IGraphicsCommandList, FrameContext, FrameStatus, GraphicsCapabilities, and the typed GPU handles.
